## 2. Agent 1: Pricing AI Agent (Dynamic Valuation Engine)

### 2.1 Role & Responsibility
The **Pricing AI Agent** predicts the fair market resale value of pre-owned electronics by synthesizing:
1. Base manufacturer retail price (MRP) and historical depreciation curve.
2. Market supply/demand velocity on major e-commerce platforms.
3. Component-level wear and tear deductions.
4. Telemetry from the 16 automated diagnostic hardware tests.
5. Regional demand elasticity (metro vs non-metro cities).

### 2.2 Pricing Formula & Depreciation Matrix
$$\text{Final Quote} = \text{Base Value} \times (1 - D_{\text{age}}) \times \prod_{i=1}^{n} (1 - D_{\text{defect}, i}) + B_{\text{accessories}} - P_{\text{risk}}$$

Where:
- $D_{\text{age}}$ = Age depreciation rate ($18\%$ year 1, $32\%$ year 2, $48\%$ year 3+).
- $D_{\text{defect}}$ = Defect penalty (e.g., Cracked screen: $-35\%$, Faulty battery: $-12\%$, Broken camera: $-20\%$).
- $B_{\text{accessories}}$ = Bonus for original bill, box, and working OEM charger ($+5\%$ to $+8\%$).
- $P_{\text{risk}}$ = Risk adjustment from the Fraud Detection Agent.

## 3. Agent 2: Diagnostics Agent (Hardware QC Evaluator)

### 3.1 Role & Responsibility
The **Diagnostics Agent** executes on the mobile client and communicates with backend inference to evaluate the integrity of the 16 hardware tests. It detects sensor spoofing (e.g., simulated accelerometer data or mock touch events) and translates sensor metrics into an objective **Device Health Score (0–100)**.

### 3.2 Evaluation Rules
```
┌─────────────────┬───────────────────────────────┬───────────────────────────────┐
│ Diagnostic Test │ Telemetry Evaluated           │ Pass Threshold                │
├─────────────────┼───────────────────────────────┼───────────────────────────────┤
│ Touch Matrix    │ Screen grid touch cells hit   │ ≥ 98% cells green within 30s  │
│ Dead Pixels     │ User visual confirmation      │ No stuck sub-pixels reported  │
│ Microphone      │ Decibel level & frequency     │ Peak amplitude > 65dB         │
│ Speaker         │ Acoustic response frequency   │ Recognized 3-digit audio code │
│ Battery         │ Battery health percentage     │ Health ≥ 80% and cycle < 800  │
│ Gyroscope       │ Angular velocity along 3 axes │ Absolute delta > 2.5 rad/s    │
│ Biometrics      │ Local Auth hardware response  │ Crypto challenge verified     │
└─────────────────┴───────────────────────────────┴───────────────────────────────┘
```

## 4. Agent 3: Fraud Detection Agent (Risk & Stolen Device Shield)

### 4.1 Role & Responsibility
The **Fraud Detection Agent** operates as an automated security filter before quotes are finalized or payouts released. It detects:
1. **IMEI Duplication:** Checks if the same device serial was submitted across multiple accounts within 30 days.
2. **GSMA Blacklist Registry:** Direct lookup to ensure phone was not reported lost/stolen.
3. **GPS Spoofing:** Flags mock location apps or discrepancies between IP geolocation and device GPS.
4. **Sudden Velocity:** Flags accounts listing more than 3 high-end devices within 48 hours.

### 4.2 Decision Matrix
- **Risk Score 0–25:** Low Risk -> Instant automated pickup approval & instant IMPS payout.
- **Risk Score 26–65:** Medium Risk -> Standard pickup with manual technician secondary verification.
- **Risk Score 66–100:** High Risk -> Block quote, freeze sell order, flag for fraud analyst review.

## 5. Agent 4: Repair Cost Agent (Smart Parts & Labor Estimator)

### 5.1 Role & Responsibility
The **Repair Cost Agent** provides instant, transparent quotes for doorstep repair requests:
- Accurately identifies whether a cracked screen requires only glass replacement or full OLED digitizer assembly.
- Balances spare parts inventory costs with technician travel distances to quote dynamic competitive prices.
- Automatically calculates parts warranty duration (default 6 months) and guarantees no hidden charges.

### 5.2 System Prompt & Prompt Template
```markdown
You are the Repair Cost Agent for Cashify Clone.
Your goal is to calculate the repair cost estimate for a device given its brand, model, and reported issues.

Guidelines:
1. Always prefer OEM-grade certified spare parts.
2. If multiple issues are reported (e.g., Screen + Battery), offer a 15% combo bundle discount on labor.
3. Output the exact cost breakdown, turnaround time in minutes, and warranty period.
4. Output strict JSON matching the RepairEstimate schema.
```

## 6. Agent 5: Recommendation Agent (Personalized Phone Matchmaker)

### 6.1 Role & Responsibility
The **Recommendation Agent** powers the refurbished e-commerce experience:
- Understands natural language user intent (e.g., "Find me a phone under ₹30,000 with the best camera and battery life for video creation").
- Weights refurbished grades (Superb vs Good) against user budget.
- Highlights trade-in upgrade paths (e.g., "Trade in your iPhone 11 and get this iPhone 13 for only ₹14,999").

## 7. Agent 6: Customer Support Chatbot Agent

### 7.1 Capabilities
- **Order Status Tracking:** Fetches live courier tracking numbers and technician ETA.
- **Pickup Rescheduling:** Modifies pickup time slots with natural language requests.
- **Warranty Claims:** Guides users through troubleshooting before filing a repair warranty ticket.
